# Design lessons: a queue, not an attic (D-UX-58)

A lesson waits here until it is decided, then leaves: accepted lessons move into `docs/DESIGN.md` (a rule) or `site/src/global.css` (a token) in the same commit; rejected and superseded ones are deleted, their line kept in `docs/DECISIONS.md` if they mattered. `npm run verify` caps this file at 6 KB. Accepted only on evidence: a principle with its source, a defect that repeats, an accessibility rule, the user tests, the usage numbers or the owner's word.

Each entry: **observation**; evidence; root cause; the rule proposed; scope; status (proposed, accepted, superseded or rejected) with the date.

## Open

1. **A control's spoken name rewrites the figure it shows.** The estimate's level buttons showed "Basic 8.40 L" and were named "Basic: Rs. 8,40,271" (UX1, 13-10-2026; fixed there). Evidence: WCAG 2.5.3 (label in name). Root cause: an `aria-label` written for a fuller figure. Rule proposed: a control's name begins with its visible text; more detail goes after it, as hidden text. Scope: every page. Status: proposed, 13-10-2026.
2. **Principle 7 contradicts the column.** The `max-w-3xl` column holds about 100 characters of 14 px text (the home page at 1280, UX1). Evidence: principle 7's own 45 to 75. Rule proposed: running text takes `max-w-prose`; `max-w-3xl` is for tables and panels. Scope: every page. Status: proposed, 13-10-2026.
3. **Links take the accent.** The home page's and the DSCR's links use `text-teal-700`, the accent's colour, not `text-link`; the ratchet counts the class but not the wrong role (UX1). Evidence: principle 6. Rule proposed: links use `text-link`, and the site check flags a teal class on an `<a>`. Scope: every page. Status: proposed, 13-10-2026.
4. **`max-w-prose` holds about 80 characters, not 65.** The home looks at 1280 wrap 14 px text inside it at 81 characters (UX2b, 13-10-2026, measured in headless Chromium's system font): `ch` is the width of a "0", wider than the average letter. Evidence: principle 7 (45 to 75; WCAG 1.4.8 caps at 80). Root cause: a width set in digits, checked by eye. Rule proposed: lesson 2 stands for a line read once (one sentence an entry, where narrowing to 75 would only orphan its last word); the design review prints the longest line at 1280, so principle 7 is measured on paragraphs. Scope: every page. Recurs in AG1: 91 to 98 characters of `text-lead` in Figtree at 1440 (home now `max-w-lg`). Status: proposed, 13-10-2026.
5. **A card-wide link shows focus only on its text.** The home page's cards (UX2b, 13-10-2026): the link's ::after makes the whole card the target and hover tints it, but the focus ring went round the question alone, in two stepped boxes when it wrapped; fixed there with the card's tint on `has-focus-visible`. Evidence: WCAG 2.4.7 met, 2.4.13 not; the design check reads only the link's own outline (`scripts/design-checks.mjs`). Root cause: hover styled on the card, focus left to the link. Rule proposed: a link stretched over its card shows focus on the card as it shows hover, and the check reads that. Scope: every card-wide link. Status: proposed, 13-10-2026.
6. **A reference line crosses the figures it is read against** (AG1's story, 13-10-2026): the 1.20 line ran through four bars' figures and "1.06" read as "1.86". Proposed: a figure's label sits on the panel's fill above any line, and the design checks flag text crossed by a line. Repeated in AG2 (14-10-2026): eight figures side by side at 360 ran together ("1.331.311.29"); the forbidden check now fails on chart figures that overlap at 360 and 320 px; on a phone only the lowest year's figure shows.
7. **A tested item must test each of its clauses; a canvas is unseen by axe** (AG1, 13-10-2026): F4 said 44 px but tested only the corners (now both); the dashes ran under the words though every contrast check passed (now kept 12 px off). Proposed: the forbidden check counts dash pixels inside text boxes, and the design review reads a page in the new look after F9's 6 s or still.
