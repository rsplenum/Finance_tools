# Traps met in the video studio

Moved from `docs/GOTCHAS.md` by REFORM1 (11-11-2026): each is about the studio's own repo, which keeps its own traps. Grep it when a film row runs here.

- **The reference films and the owner's uploads live only in the session that received them** (02-11-2026, VID3): `/root/.claude/uploads/<session>/` is gone in the next session, and the films are a third party's, so not committed; `docs/video/VID3-path.md` §1 keeps their measured numbers, and the owner attaches the films again when a row needs to look at them.
- **The studio's edge check and huge type** (02-11-2026, `lib/figures.mjs` `cutText`): a line's box is taller than its ink. A 540 px glyph's box passes the frame while the glyph sits inside, so one line is judged by its ink (canvas `measureText`). A wrapped line is still judged by its box: set a hero on one line.
- **A beat read from sound comes out at half speed** (02-11-2026, `lib/measure.mjs` `tempo`): the double period correlates as strongly as the beat. Take the shortest period within 80% of the strongest, 60 to 150 bpm. A silent film has no beat until `video.json` gives `bpm`.
- **PIL does not load here** (02-11-2026, VID3b): `from PIL import Image` fails with "cannot import name '_imaging'". Tile a contact sheet with ffmpeg instead: `scale` each PNG, then `hstack` and `vstack` in one `-filter_complex`.
- **A name declared twice in a module scene kills every animation** (02-11-2026, VID3c, `scenes/dscr-film/index.html` in the studio): a `<script type="module">` that declares a name twice (`const red` and later `let red`) throws before it builds anything, so the page stands still and the probe counts 0 animations. Read the page error first when a draft shows no motion.
- **Web Animations chained on one property fight under `fill: both`** (02-11-2026, VID3c, `scenes/_shared/kit.js`): the animation made last wins on every frame, even before it starts, so earlier moves vanish and a frame depends on the order of seeks. Build each element's property as one track over the whole film (`film.track`, D-TECH-92).
- **Size text to fit only after its fonts load** (02-11-2026, VID3c, `kit.js` `fill`): measured before the face loads, the width is the fallback font's and the hero comes out the wrong size. `ready(build, { fonts })` waits on `document.fonts.load` for each face first; name every face a filled line uses.
- **AAC overshoots the peaks of a mix** (02-11-2026, VID3c, `lib/sound.mjs`): a soft-clipped mix at -1.6 dBFS came out at 0.1 dBTP after AAC, and a transient on a window's first sample slipped past a limiter that counted the time before the file as gain 1. Measure loudness and true peak on an AAC round trip and hold peaks with a gain curve, never by bending the wave (D-TECH-95).
- **Filter, opacity below 1 or overflow flatten a CSS 3D group** (03-11-2026, VID3d, `scenes/_shared/world.js` in the studio): any of them on an element with `transform-style: preserve-3d` turns it into a flat picture, so its children lose their depth and sort wrongly. Put blur (depth of field) and fade (fog) only on the leaves, never on a group; and `rotateX(90deg)` with its origin at `0 0` turns local +y into world +z (toward the viewer), so a sheet laid on the ground faces up only that way.
- **A studio scene's CSS px are the 540 or 960 page, not the 1080 or 1920 video** (03-11-2026, VID3d): the page is 540x960 (or 960x540) at device scale 2. A HUD line placed at `top: 1500px` is off the page; place it in page px, or project it from the world (`world.project`) so it sits under the thing it names.
- **A percentage width in a canvas font is invalid and falls back to 10 px** (03-11-2026, VID3d, the ring's O): `ctx.font = '800 200px 75% Anek'` is rejected without an error and the text is measured at 10 px sans-serif. Set `ctx.font = '800 200px Anek'` and `ctx.fontStretch = 'condensed'`, and check the measured width is plausible before using it.
- **The film gate reads the command's text, not what it runs** (03-11-2026, CD1; since CD2 the studio's `.claude/hooks/film-gate.mjs`, run here by the small hook of the same name): any Bash call whose text holds a studio render of a film without a greenlight is stopped, a `grep`, `echo` or `pkill` included. To stop a running render use a pattern that does not spell the command (`pkill -f "studio[.]mjs"`); to test the gate, put its JSON in a file. **Noise through a moving filter is wind** (VID3d, the studio's `lib/sound.mjs` bed, deleted in CD2): a low-pass or band over white noise that swells or sweeps reads as wind or a car at speed, however it is labelled ("air", "riser", "whoosh").
- **Directors from one model converge** (03-11-2026, VID3e, the studio's `creative-department`): round 1's three directors, each alone and on a different door, all chose a printer in a small Indian town buying a second press, and two named Sivakasi. The doors do not stop a shared first idea; the reviewer's reasons in round 2 broke it (a baker, a weaver, a khakhra maker). Judge a round's spread before the verdict, and never steer a director toward a trade: that is the producer writing a concept.
- **A focus inside a filmed page scrolls the stage** (07-11-2026, VID6a, the studio's `tour-film/engine.js`): `focus()` on a field in an iframe also scrolls the parent's `overflow: hidden` boxes (`#lens` moved 138 px), so the spotlight drawn from the page's own rectangles sat a label below its field for the rest of the film. Focus with `{ preventScroll: true }`; `draw` puts `#stage`, `#lens`, `#win`, `#view` back to 0 each frame.
- **A tour `scroll` cue needs a real element** (07-11-2026, VID6a2, the studio's `tour-film/engine.js` `scroller`): `union` and `clipped` anchors in `stage.js` only lend a rectangle, so a `scroll` on one dies on `ownerDocument` and the render stops. Scroll to one real field, then `cam` and `spot` on the union.
- **A tour beat that uses `end` must take it** (08-11-2026, VID6a3, the studio's `tour-film/stage.js` `beat`): `(t) => { … stamp(t, end, …) }` throws "end is not defined" in the page and `render.mjs` dies 30 s later on a `waitForFunction` timeout, with no line number. Write `(t, end) =>`
- **The studio's `npm test` hangs in a cloud session** (08-11-2026, VID6a3): `test/check.test.mjs` renders through `lib/render.mjs`, whose Playwright wants its own `chromium_headless_shell-1194`, absent here (the container has `/opt/pw-browsers/chromium`); the launch fails and the test never exits. Run `node --test test/film-gate.test.mjs test/measure.test.mjs` for a tour row; a fix is `executablePath` in `lib/render.mjs`, outside a film row
- **A tour label on a paper is not checked against its text** (08-11-2026, VID6b, the studio's `tour-film/engine.js` stamps): the "covers page text" check reads the live pages' text lines only; a paper (PDF, Word, Excel) is a picture, so a label lands on its words unseen (Gate 2 found EVERY YEAR and WORD so). Place a label on a paper by `side: { x, y }` in a blank margin and look at the still. A cue before 0 (`cam(-1, …)`) runs on frame 0, so the film opens already in place.
